# NPTEL Assignments

This folder contains all NPTEL assignments completed as part of the **Operating Systems and System Programming (OSSP)** course.

## Folder Structure

Assignments are organized using the course naming convention.

### Naming Convention

- `week-11` → Week 1, Task 1
- `week-12` → Week 1, Task 2
- `week-21` → Week 2, Task 1
- `week-22` → Week 2, Task 2

## Example Structure

```text
NPTEL_Assignments/
├── week-11/
├── week-12/
├── week-21/
├── week-22/
└── ...
```

Each assignment folder may contain:

- Source code (`.c`)
- Input and output files
- Assignment PDF (if provided)
- README.md (if required)

This folder will be updated throughout the OSSP course as new NPTEL assignments are completed.
